# Овчарка 7 — мастерская обводки по оригиналу

Дата: 25.11.2026. Страница: `/shepherd-v6j3w/`. Ветка: `shepherd6`. Основа — тикет #174 («Овчарка 7 — оригинал» как вид в гипсе, a5d39ad, закрыт).

## Зачем

Виталий хочет сам задавать, где у овчарки швы (границы плит), обводя их по оригиналу модели Meshy 1 в 1. Плиты конвейера (Овчарка 6) отходят от оригинала, кальки на них рвутся, точно по ним не обвести. Так уже сработало на голове Добермана: Виталий обводил линии на скринах, Claude собирал по ним новую фигуру. Теперь — то же, но прямо в мастерской, без скринов: линии сразу лежат на 3D-поверхности, и их координаты точны.

Цикл: Виталий обводит пером на Овчарке 7 (с одного ракурса или с нескольких — крутить можно правой кнопкой), жмёт «Сохранить» → отдаёт файл .json → Claude собирает по линиям новую собаку с гранями → Виталий обводит дальше. Сборка собаки по линиям — **отдельная работа, не эта спека** (см. «Дальше»).

## Цели

1. Овчарка 7 — рабочая фигура «без расчёта»: модель Meshy 1 в 1 (158 336 треугольников), в гипсе, «Править фигуру» открывает только кальки и разметку.
2. Три кальки на выбор (по одной за раз, переключателем рядом с галочкой «Калька»):
   - **«Текстура»** — сама текстура Meshy, перекрашенная: гипс — фон, белые швы текстуры — тёмные линии. 1 в 1 до пикселя (та же картинка на той же модели, линии из неё не вытаскиваем).
   - **«Фото спереди»** — исходное фото Meshy (`ref-front`), спроецированное на гипс спереди, как проектор.
   - **«Фото сбоку»** — `ref-profile`, спроецированное сбоку, зеркально на обе стороны (собака симметрична).
3. Перо и всё, что уже есть у разметки (#150, #151): карандаш, линия, зачёркивание, магнит, зеркало, сглаживание, очистка. Левая кнопка рисует, правая крутит.
4. Свободные концы линий (ни к чему не прицеплены) — красные точки: видно, где контур не замкнут.
5. «Сохранить» — как у всех фигур: версия в браузере + файл .json; в файле — разметка в кадре фигуры (мм).
6. **Переиспользуемость** (требование Виталия): режим «оригинал для обводки» не привязан к овчарке. Любая модель с текстурой, открытая через «Открыть модель» (GLB из Meshy — текстура внутри; или OBJ + PNG текстуры двумя файлами), сразу открывается в этом режиме: гипс, калька «Текстура», перо, «Сохранить» — без участия Claude. Овчарка 7 — первая фигура этого режима, а не особый случай в коде.
7. Фото — отдельный шаг для каждой новой модели: совмещение фото с моделью (камеры ракурсов) пока делает Claude у себя; на странице фото-калька появляется, когда для фигуры есть фото и камеры. Без фото всё остальное работает.

## Не цели

- Сборка собаки (плит) по линиям — следующая спека.
- Кнопка «сделать грани» в мастерской — потом, когда цикл заработает.
- Правка самой текстуры как картинки — не делаем (решение Виталия: рисуем линии сразу).
- Фото сзади и 3/4 — не берём (вскользь по бокам — каша; решение Виталия).
- Ручная подгонка фото (сдвиг/масштаб ползунками) — только если автоматической не хватит, отдельным тикетом.
- Расчёт плит, деталей, раскроя, массы на Овчарке 7 — нет.
- Овчарки 1–6, их кальки и «Овчарка 5 — оригинал (вид)» не меняются.

## Анти-цели (провал, даже если «работает»)

- Перо тормозит на 158 тыс. треугольников (рывки при ведении линии).
- Калька «Текстура» не совпадает со швами при включённой «Текстуре» Meshy.
- Линии пера не видны на фоне кальки или фото.
- Открытие Овчарки 7 запускает расчёт и вешает вкладку.

## Ограничения

- GitHub Pages: только HTML/CSS/JS в браузере, three.js r128 из `vendor/`, ничего со сторонних серверов.
- Одна логика в мастерской: перо, «Сохранить», версии — те же функции, что у остальных фигур (`markup.js`, `figJSON`, `verPut`), без копий.
- Данные — уже есть: `js/orig-shepherd5.js` (V, T, F — 4,7 МБ), `img/orig-shepherd5.png` (текстура Meshy). Фото — из `from-dev/art/tools/plates/src/shepherd5/` (`ref-front.png`, `ref-profile.png`, 1024²; там же `proj/g-front.png`, `proj/g-profile.png` — те же фото с белым фоном) и камеры ракурсов `proj/cams.json` (орто-камеры, в которых снята модель; по ним #142/#173 сопоставляли фото с моделью). На страницу едут копии картинок в `shepherd-v6j3w/img/`, грузятся по выбору кальки.
- Только десктоп (у разметки на телефоне инструментов нет — как сейчас).

## Как устроено (то, что решено)

- **Где живёт.** Пока — на `/shepherd-v6j3w/`, ветка `shepherd6` (репозиторий публичный — ветка видна). Отдельная страница по неизвестной ссылке или только локально — решит Виталий потом.
- **Режим.** Один режим «оригинал для обводки» на входе принимает {V, T (uv), F, текстура (картинка или нет), фото (необязательно): [{картинка, камера, зеркало}]}. Источники: встроенная фигура (`FIGURES.<id>` с флагом режима и данными `ORIG.<id>`) и файл из «Открыть модель» (OBJ/GLB/STL — всегда этот режим; .json — как раньше).
- **Фигура.** `FIGURES.shepherd7_orig` — первая встроенная фигура режима (не `poly`, не `view`): сетка из `ORIG.shepherd5` в кадре фигуры (мм), гипс.
- **Открытие файла.** `parseGLB` дописать: uv (`TEXCOORD_0`) и картинка текстуры (`images` → `bufferView`); OBJ — uv из `vt`, PNG — вторым выбранным файлом (`fileIn` с `multiple`). Без uv или без картинки — режим без кальки «Текстура». Открытие не вызывает расчёт (`compute`), панели расчёта, цифры сверху, «Углы», таблицы деталей скрыты; видны «Править фигуру», кальки, разметка, «Сохранить».
- **Перо на 158 тыс. треугольников.** Поиск точки под курсором и укладка штриха на поверхность (`mkDrape`) — с ускорением (сетка по клеткам, как `tlGrid`, или BVH), чтобы ведение линии шло без рывков.
- **Калька «Текстура».** Шейдер на модели: берёт текстуру Meshy, светлое (швы) → тёмный цвет линий, остальное → гипс.
- **Калька «Фото».** Шейдер-проектор: точка модели → пиксель фото через орто-камеру ракурса из `cams.json` (тот же расчёт, что `camera()` в `project.js`, с переводом из кадра OBJ в кадр фигуры). Точки, обращённые от камеры, — гипс. Для бока — зеркальная камера на вторую сторону. Белый фон фото — гипс.
- **Сохранение.** `figJSON` для режима пишет только имя, источник и разметку `mk` (в кадре фигуры, мм), без сетки. Встроенная фигура — ссылка на основу (`shepherd7_orig`); модель из файла — имя файла модели (Виталий присылает Claude оба файла). Версия в браузере — как у всех.

## Оставлено исполнителю

- Как именно скрывать панели (класс на `body`, как `origview`, или отдельный флаг) — по месту, лишь бы одна логика.
- Ускорение поиска точки: сетка или BVH — по замеру.
- Как в шейдере отделить фон фото от собаки (альфа `ref-*` или белый `g-*`).
- Как искать шов текстуры под курсором для магнита (выборка картинки в окрестности по uv треугольника или по экрану) — по замеру скорости.
- Точные цвета в пределах решённого.

## Дальше (не эта спека)

- Сборка собаки по линиям — Claude руками и скриптами при каждом присланном файле, как голова Добермана: режет оригинал по линиям (точки — на поверхности, в 3D), обведённые куски → плоские плиты, где не обвёл — плиты конвейера; замкнутые контуры → плиты, щели до 6 мм — свести, открытые концы — замкнуть по шву текстуры или соседней линии, иначе по кратчайшей с пометкой; в отчёте — где плита отошла от оригинала больше допуска (там дорезать). Результат — фигура «Овчарка 7.N» в выпадашке. Рисовать дальше — на оригинале Овчарки 7, разметка копится.
- Отдельная спека — только если понадобится кнопка «сделать грани» в мастерской.
