# Вкладки мангала, чертежи и карты, рысь без тормозов: план работ

> **Для агентов:** ОБЯЗАТЕЛЬНЫЙ ПОД-СКИЛ: superpowers:subagent-driven-development (рекомендуется) или superpowers:executing-plans, задача за задачей. Шаги — чекбоксы (`- [ ]`). Одна задача = один тикет (`/to-tickets` запускает Виталий).

**Цель:** редактор мангала отдаёт три комплекта файлов на оценку (лазер с листа, лазер из заготовок, гильотина), показывает металл с весом, считает чертежи и карты по кнопке; рысь открывается без зависания.

**Архитектура:** правки только в `editor/`. Раскладку мангала заменяем на MaxRects с лендинга (по рамкам деталей, контур выводится как был). Кнопку «Рассчитать» делает один общий модуль `editor/common/calc.js`, его берут и мангал, и рысь (правило «одна логика» из `CLAUDE.md`). Чертежи и карты переносим с `md/` в `editor/mangal/js/` и правим под детали редактора.

**Стек:** HTML, CSS, JavaScript в браузере, three.js r128 из `vendor/`. Тесты: `node:test` + `vm` (новые), `editor/mangal/tools/smoke.js` (есть), Playwright (`tests/e2e/editor.spec.js`).

**Спека:** `docs/superpowers/specs/2026-11-09-mangal-cut-tabs-design.md` — читать вместе с планом, особенно таблицу «Решения грилинга».

## Общие ограничения

- `index.html` и `md/` не трогаем вообще (лендинг заморожен). Алгоритм раскладки рыси (`editor/lynx/js/prod.js`, `nestGen`) не трогаем.
- Только HTML, CSS, JS в браузере; при открытии страницы ни одного запроса на сторонние серверы.
- Телефон 390 × 844 без горизонтальной прокрутки страницы; таблицы листаются внутри `.tbl`.
- Поменялся `js/*.js` или `css/*.css` страницы — новая дата в `?v=` у всех её `<script>` и `<link>` (`editor/mangal/index.html`, `editor/lynx/index.html`).
- Одна логика в мангале и рыси: вкладки, «Рассчитать», скачивание, PDF. Расхождение — только с причиной в спеке.
- Команды тестов на этой машине: `NODE_OPTIONS=--use-system-ca npm test`, `NODE_OPTIONS=--use-system-ca npm run test:editor`, `NODE_OPTIONS=--use-system-ca npx playwright test`. Все зелёные перед коммитом.
- Ветка `landing-v2-mangal`, в `master` — только по команде Виталия.
