# Овчарка 7: дожать кальку «Фото спереди» — план

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** калька «Фото спереди» на «Овчарка 7 — оригинал» без лишнего контура уха, с дотянутыми ушами, с резкими гранями (как на исходном фото) и без ступеньки между слоем головы и слоем тела.

**Architecture:** часть правок — в подготовке картинок (`tools/photo-fit.js`: убрать контур силуэта, заранее деформировать фото головы по точкам ушей), часть — в шейдере кальки (`js/owork.js` `owPhotoMat`: без светотени, без размытия, резкие швы, плавный переход голова/тело). Чистые функции — в `js/ow-core.js` и в самом `photo-fit.js` (экспорт для тестов).

**Tech Stack:** браузерный JS без сборки, three.js r128, Node (`photo-fit.js`, PNG — `from-dev/art/tools/plates/png.js` + свои `writePNGA`/`readAlpha`), `node --test`, `tools/smoke.js`.

**Spec:** `docs/superpowers/specs/2026-11-25-shepherd7-workshop-design.md` + замечания Виталия 26.11 ниже (главнее спеки).

## Global Constraints

- Только HTML/CSS/JS в браузере; three.js r128 из `vendor/`; ничего со сторонних серверов; новых npm-зависимостей нет.
- Одна логика: та же калька для всех фигур с `photos` — без копий шейдера.
- Овчарки 1–6, их кальки, «Овчарка 5 — оригинал (вид)», галочка «Текстура» (#146), калька «Текстура» (#177) — не меняются.
- Подгонка «Фото сбоку» (матрица `m`, `head` сбоку) — не меняется.
- Каждое фото в `img/` ≤ 1 МБ; картинки грузятся по выбору кальки, как в #178.
- `photo-fit.js` пересобирает `js/photos-shepherd7.js` и `img/photo-shepherd7-*.png`; команда запуска — в шапке `photo-fit.js` обновить, повтор даёт файлы байт в байт.
- Поменялся `js/*.js` или `css/*.css` — новая метка `?v=` во всех тегах `shepherd-v6j3w/index.html`.
- Перед коммитом: `NODE_OPTIONS=--use-system-ca npm test`, `NODE_OPTIONS=--use-system-ca npm run test:editor`, `node --test shepherd-v6j3w/tools/`.
- Код — плотные однострочники; `//` не посреди строки.
- Совпадение силуэта (`iou` в логе `photo-fit.js`) по каждому виду не ниже, чем сейчас: спереди 0,858, голова спереди 0,849, сбоку 0,890, голова сбоку 0,975.

## Review Focus

1. **Контур убран вместе с тёмной гранью у края.** У фото тёмные грани касаются чёрного контура; если резать «всё тёмное у фона», съест и грань. Ожидание: убирается только полоса контура (≤ ширины контура от прозрачного фона), тёмные грани глубже остаются. Тест — Task 1.
2. **Деформация по точкам ушей сдвинула глаза/нос.** Ожидание: точки глаз и носа (3 нынешних пина) после деформации — на месте (≤ 1 px). Тест — Task 2.
3. **Резкость дала «лесенку» и мерцание при вращении.** Без мип-карт текстура на мелком масштабе рябит. Ожидание: при «Всё» (вся собака в кадре) нет мерцающей ряби — анизотропная фильтрация, не `NearestFilter`. Проверка — скриншоты Task 3 на двух масштабах.
4. **Плавный переход голова/тело на ухе.** Если полоса перехода прошла через ухо, на ухе снова два контура полупрозрачно. Ожидание: полоса перехода — ниже основания ушей. Тест — Task 4.
5. **Обратные поверхности.** Затылок, обратная сторона уха — по-прежнему гипс (правило #178: нормаль от камеры фото → гипс). Тест — Task 1 (скрин сзади).

### Task 1: убрать контур силуэта с фото

**Files:** `tools/photo-fit.js`, `tools/photo-fit.test.js`; пересборка `img/photo-shepherd7-front*.png`, `img/photo-shepherd7-side*.png`.

**Interfaces:**

Экспорт для теста (`module.exports` при `require`, как `writePNGA`).

- [ ] **Step 1: Тест** на синтетике 40 × 40: фон прозрачный, квадрат серый 0,5 с чёрной рамкой 2 px снаружи и тёмной полосой 2 px внутри серого на 6 px от края → после `stripOutline(…, 4)`: рамка прозрачная, тёмная полоса внутри и серый — нетронуты.
- [ ] **Step 2: Красный** (`node --test shepherd-v6j3w/tools/photo-fit.test.js`).
- [ ] **Step 3: `stripOutline`**; `maxPx` для фото — по ширине контура на `g-front.png` (замерить, записать в шапку). Зелёный.

### Task 2: дотянуть уши — деформация фото головы по точкам

**Files:** `tools/photo-fit.js`, `tools/photo-fit.test.js`; пересборка `img/photo-shepherd7-front-head.png`, `js/photos-shepherd7.js`.

**Interfaces:**
- Produces: `warpByPins(rgba, w, h, pins:[[gx,gy,tx,ty],…]):Uint8Array` — картинка, где пиксель фото `(gx,gy)` переезжает в `(tx,ty)` (координаты фото после аффинной подгонки), между пинами — кусочно-аффинно по треугуляции пинов + 4 угла картинки (углы на месте). Точки вне треугуляции не двигаются.
- Produces: аргумент `front-head-warp=<gx,gy:tx,ty;…>`; точки ушей по умолчанию считаются сами: кончик уха = верхняя точка силуэта в левой/правой половине, основание = нижняя точка выреза между ухом и лбом — на фото и на снимке модели; найденные точки — в лог и в шапку.

- [ ] **Step 1: Тесты `warpByPins`:** (а) пины `g=t` → картинка байт в байт та же; (б) один пин сдвинут на (5,0) → пиксель-метка у пина переехал на 5 px (±1), пиксели у углов — на месте; (в) три пина глаз/носа из нынешней команды с `g=t` + пины ушей со сдвигом → пиксели глаз/носа на месте (±1 px).
- [ ] **Step 2: Красный.**
- [ ] **Step 3: `warpByPins` + поиск точек ушей.** Зелёный.
- [ ] **Step 4: Пересобрать** фото головы спереди; `iou` головы спереди ≥ 0,849 и выше, чем без деформации (оба числа — в лог и комментарий).
- [ ] **Step 5: Скриншоты** `p2-front.png`, `p2-34left.png` — край уха фото совпадает с краем уха модели (на глаз ≤ 2–3 мм), глаза и нос не сдвинулись относительно `p1-*`.

### Task 4: плавный переход голова / тело
