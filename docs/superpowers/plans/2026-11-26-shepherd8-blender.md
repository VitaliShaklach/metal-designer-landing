# Овчарка 8 — блендер: швы гранёной модели на цветной форме — план

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** «Овчарка 8 — блендер» — цветная модель Meshy (красивая форма, узкая морда) с белыми швами, перенесёнными с гранёной серой модели (из трёх согласованных серых фото), — на странице `/shepherd-v6j3w/` фигурой режима «оригинал для обводки» (как Овчарка 7, #175).

**Architecture:** две задачи. 1 — кухня вне git: Blender (5.3, командная строка) совмещает серую модель A с цветной B **по частям** и запекает текстуру A на развёртку B (bake «selected to active»). 2 — страница: модель B со швами → `js/orig-shepherd8.js` + картинка текстуры генератором `from-dev/art/tools/plates/orig.js`; строка `FIGURES.shepherd8_orig` с `ow` — тот же режим, что у Овчарки 7, новых механизмов нет.

**Tech Stack:** Blender 5.3 (`C:\Program Files\Blender Foundation\Blender 5.3\blender.exe -b --python`), numpy и mathutils внутри Blender; Node (`orig.js`, smoke); three.js r128 на странице.

- [ ] **Step 1: Части.** В кадре после общего ICP (как v1) делим A и B на части по простым правилам в долях габарита: хвост (за крупом, выше скакательных суставов), задняя левая и правая лапа (сзади, ниже линии живота, по знаку X), уши (выше макушки). Остальное — туловище с головой (как в v1).

Печать: медиана и 90 % расхождения по каждой части, мм (×1000).
