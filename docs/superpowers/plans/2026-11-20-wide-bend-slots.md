# Широкие прорези по линиям сгиба — план

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** на скрытой странице собаки старая перфорация (щели одной линией) заменяется широкими прорезями-«таблетками» с пазами от кромки, все размеры настраиваются.

**Architecture:** вся геометрия прорезей уходит в новый чистый файл `dog-k7q2m/js/slots.js`: раскладка вдоль линии (1D), форма прорези, врезка паза в контур, длина и перенос фигур с дугами. `sheets.js` берёт оттуда прорези и контур с пазами для DXF, метража и чертежей, `ui.js` и `index.html` отвечают за настройки. Фигура с дугами — `{pts:[[x,y]…], b:[bulge…]}`: `b[i]` задаёт дугу на ребре `pts[i]→pts[i+1]`, как код 42 в DXF; 0 — прямая, ±1 — полуокружность.

**Tech Stack:** обычный JS в браузере (глобальные функции, без сборки), тесты — `node dog-k7q2m/tools/smoke.js` (vm, `ok(условие, 'текст')`), DXF R12 ASCII.

**Spec:** `docs/superpowers/specs/2026-11-20-wide-bend-slots-design.md`

**Interfaces:**
- Produces:
  - `slotPlan(L, openA, openB, o) → [[t0,t1],…] | null` — отрезки реза вдоль линии длиной `L`, в мм от её начала. `openA/openB` — у этого конца крайняя прорезь до края. `o = {w, len, br, eb, el}`. Правила по порядку:
    1. Крайние: `a = openA ? el : 0`, `b = openB ? el : 0`. Если оба открыты и `L < 2·el + eb`, то `a = b = (L − eb)/2`. Если открыт один и `L < el + eb`, то он `= L − eb`. Открытая крайняя короче `w` — вернуть `null`.
    2. Середина `M = L − (a ? a+eb : eb) − (b ? b+eb : eb)`. При `M < w` средних нет (перемычка между крайними длиннее — это нормально). Иначе `n` средних одной длины `c = (M − (n−1)·br)/n`, `n` — наименьшее при `c ≤ len`.
    3. Нет ни крайних, ни средних — вернуть `null`. Одной прорези от края до края не бывает по правилу 1 (между крайними всегда минимум `eb`).
  - `slotShape(a, u, t0, t1, w, D=0) → {pts, b}` — замкнутая «таблетка» на прямой `a + u·t` от `t0` до `t1` (длина вместе с закруглениями). 4 точки, `b` с двумя дугами по ±1 так, чтобы середина каждой дуги лежала снаружи прямоугольника, то есть на `t0` и на `t1`. При `D > w` вместо полукругов — разгрузочные отверстия («замочная скважина»): круг Ø`D` с центром в `t0 + D/2` (и `t1 − D/2`), полоса ширины `w` входит в круг в точках касания `±w/2`, дуга круга — большая (больше 180°, `|b| > 1`). Весь круг внутри `t0…t1`.
  - `notchInto(C, notches) → {pts, b, miss:[k…]}` — контур `C` (массив точек) со вставленными пазами. `notch = {p, u, d, w, D=0}` (`D > w` — разгрузочное отверстие на внутреннем конце, как у `slotShape`): `p` — конец линии на кромке, `u` — единичное направление внутрь детали, `d` — глубина паза от `p` до дальнего конца, включая закругление. Устье — пересечения прямых `p ± n·w/2` (вдоль `u`) с ребром `C`, ближайшим к `p`. Оба пересечения должны лежать на этом ребре, иначе паз не вставляется, а его индекс попадает в `miss`. Без пазов `b` — нули.
  - `shapeLen({pts,b}) → number` — периметр с дугами (длина дуги по хорде `c` и `θ = 4·atan(b)`: `c·θ / (2·sin(θ/2))`).
  - `shapeFlat({pts,b}, k=8) → [[x,y]…]` — дуги ломаной из `k` отрезков, для SVG.
  - `shapeTr({pts,b}, T) → {pts,b}` — перенос точек функцией `T`. Если `T` меняет знак площади (`area2` из `prod.js`), знаки `b` меняются.
  - `const SLOT_DEF={w:2,len:20,br:3,eb:3,el:20,notch:true,D:0}`.
