# Конь: страница с тремя вариантами — план работ

> **Для агентов:** ОБЯЗАТЕЛЬНЫЙ ПОД-СКИЛ: superpowers:subagent-driven-development (рекомендуется) или superpowers:executing-plans, задача за задачей. Шаги — чекбоксы (`- [ ]`). Тикеты: задачи 1–3 — тикет «Кони», задачи 4–5 — тикет «Страница» (Q7). `/to-tickets` и `/implement` запускает Виталий.

**Цель:** скрытая страница `/horse-r4t9p/` с тремя встроенными фигурами Конь (50), Конь (100), Конь (150), собранными из одной модели Meshy и прошедшими фильтры чистки.

**Архитектура:** движок копируем из `dog-k7q2m/` (сам он — копия редактора рыси). Фигуры собирает один раз Node-скрипт `horse-r4t9p/tools/make-horse.js` в `vm`-контексте с движком, как `smoke.js`:
- эталон `from-dev/…/horse150.obj` → ориентация и масштаб 800 мм;
- половина → упрощение → зеркало → грани-многоугольники → чистка → проверка;
- результат — `js/plates-horse{50,100,150}.js` в формате `MODELS_POLY`, плюс отчёт и картинки.

На сайте фигуры только читаются, ничего не считается заново.

**Стек:** обычный JS без сборки, three.js r128 из `vendor/`, Node 24 (`vm`, `node:test` не нужен — проверки в `smoke.js`), без новых зависимостей.

**Спека:** `docs/superpowers/specs/2026-11-20-horse-page-design.md`. Читать вместе с планом; где текст спеки расходится с таблицей «Решения грилинга», действует таблица.

## Общие ограничения

- Доберманью страницу `dog-k7q2m/`, лендинг (`index.html`, `md/`, `lynx/`) и `editor/` не трогаем. Smoke собаки проходит, как до работы.
- Только HTML/CSS/JS в браузере, библиотеки локально (`../vendor/`), ничего со сторонних серверов.
- Телефон 390 px без горизонтальной прокрутки.
- `from-dev/` в git не идёт: скрипт читает эталон оттуда, в репо кладём только готовые `plates-horse*.js`.
- Пороги правил (из спеки, менять нельзя):
  - плоскость ≤ 0,1 мм;
  - рёбра ≥ 5 мм;
  - ступеньки ≥ 8 мм;
  - углы ≥ 5°;
  - узкие ≥ 15 мм;
  - самопересечений 0;
  - симметрия ≤ 0,1 мм;
  - грани наружу;
  - вырожденных 0;
  - похожесть ≤ 2 мм от упрощённой модели до чистки.
- Высота по умолчанию 800 мм (Q2), фильтры работают в 800 мм.
- Лишние швы (излом < 5°) не сливаем, только список в отчёт.
- Каждый вариант кладём в выпадашку, даже если правило не выполнено (Q5). Невыполненное — поимённо в отчёте.
- Коммиты локально, push только по команде Виталия. Метка `?v=` у всех `<script>` и `<link>` страницы — одна дата.

## На что смотреть ревьюеру

1. **Упрощение ломает симметрию.** Если QEM-упрощать целую модель, он режет левую и правую стороны по-разному. Поэтому упрощаем половину и отражаем, а точки на шве (x = 0) держим на плоскости. Тест: `checkFigure().sym` пуст у всех трёх.
2. **Шов по середине.** После зеркала точки на x = 0 у двух половин должны слиться в одну. Иначе там останется щель, открытые рёбра и детали-двойники. Тест: открытых рёбер 0 (модель замкнутая).
3. **Морда не туда.** Редактор ждёт Y вверх и морду на +Z, иначе виды «Спереди» и «Сбоку» перепутаются. Тест: самая передняя точка (max Z) — у носа, ниже середины высоты; уши — max Y.
4. **Чистка «съедает» Конь (50).** Слияние узких деталей на 50 гранях может уйти в каскад. Отчёт показывает, сколько деталей было до и после. Если ушло больше чем на 20 %, это красная строка в отчёте, а не молчаливый результат.
5. **Выпадашка и адрес.** `#f=horse100` открывает нужного коня, а сохранённая в браузере фигура собаки (`store('art-fig')` = `doberman11`) не ломает страницу коня. Тест в smoke: список «Фигура» — ровно три коня, выбор по умолчанию `horse150`, а неизвестный id откатывается на `horse150`.

**Интерфейсы:**
- Даёт: `require('./check.js')(run)` → `checkFigure(E, o) → R`.
  - `E = {V:[[x,y,z]], P:[[i…]], S:[]}`; `o = {sym:true, ref:E0|null}`.
  - `R` — массивы номеров граней или точек по правилам:
    ```
    {planar:[pi], short:[[a,b]], step:[[a,b]], needle:[pi], narrow:[pi],
     selfX:[pi], pierce:[[pi,pj]], sym:[i], flipped:[pi], degenerate:[pi],
     open:[[a,b]], far:[i], extra:[{f1,f2,dih}], parts:Number}
    ```
  - `far` — точки дальше 2 мм от `o.ref`.
  - `extra` — швы с изломом < 5°.
  - `parts` — число деталей по `buildParts`.
- Использует из движка: `polyDev`, `selfXPolys`, `piercePolys`, `openVerts`, `mirrorMap`, `polyNorm`, `buildParts`, `flatten` (`minW`).
