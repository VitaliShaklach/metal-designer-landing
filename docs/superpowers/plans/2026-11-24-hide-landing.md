# Спрятать главную страницу лендинга (не удалять)

Решение Виталия 24.11.2026. Статус: в очереди, тикета пока нет.

## Что

Главная лендинга с рекламой — `https://vitalishaklach.github.io/metal-designer-landing/` (корневой `index.html`, адреса вида `/#len=800&wid=420&top=970&t=4&deep=1`) — убрать из доступа. Файлы не удалять.

Не трогать: `https://vitalishaklach.github.io/metal-designer-landing/editor/` (редактор) и скрытые страницы (`dog-k7q2m/`, `karkas-w5n8x/`, `horse-r4t9p/`, `shepherd-v6j3w/`, будущий дровокол).

## Ограничение, которое надо решить до тикета

Репозиторий публичный, сайт на GitHub Pages. «Ни у кого нет доступа» на 100 % так не сделать: всё, что лежит в публичном репозитории, можно открыть на github.com. Варианты:

1. Корневой `index.html` заменить заглушкой (пустая страница или переход на редактор), а лендинг перенести в папку со случайным именем, как скрытые страницы. Открыть его сможет только тот, кто знает адрес. Код остаётся в репозитории.
2. Сделать репозиторий приватным. Тогда доступ закрыт по-настоящему, но GitHub Pages для приватного репозитория на бесплатном аккаунте не работает: отключится весь сайт, включая редактор и скрытые страницы.
3. Убрать лендинг из ветки в отдельную ветку (`landing-archive`). Сайт его не показывает, файлы целы в git.

Нужен выбор Виталия, затем тикет.
