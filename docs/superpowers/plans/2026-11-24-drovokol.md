# Дровокол: план работ

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Скрытая страница `drovokol-q7m4z/`: цех задаёт количества пластин, ручек (A/B × профиль 1–5 × 60/70/80) и ушей, жмёт «Рассчитать» и скачивает один DXF с раскладкой по листам плюс список «Что купить».

**Architecture:** Чистый браузерный JS без сборки, по образцу `horse-r4t9p/`. Геометрия — функции, отдающие контуры в мм; раскладка и запись DXF скопированы из `horse-r4t9p/js/prod.js`; кнопка «Рассчитать» — общий `editor/common/calc.js` (подключается, не правится). Проверка ядра — `tools/smoke.js` в Node через `vm`, как у коня.

**Tech Stack:** HTML, CSS, vanilla JS (глобальные функции в файлах `js/*.js`, порядок подключения важен), Node `vm` для smoke, Playwright для e2e.

**Spec:** `docs/superpowers/specs/2026-11-24-drovokol-design.md` (таблица «Решения грилинга» в конце главнее текста). Черновик геометрии с теми же числами: `c:\Work\drovokol\plate.py`.

## Global Constraints

- Только HTML/CSS/JS в браузере; ничего со сторонних серверов; работает на 390 px без горизонтальной прокрутки (CLAUDE.md).
- `editor/` и лендинг (`index.html`, `md/`) не правим. `editor/common/calc.js` только подключаем: `<script src="../editor/common/calc.js?v=…">`.
- Метка `?v=дата` у всех своих `<script>` и `<link>` на странице; поменялся файл — меняем дату во всех тегах.
- Металл один на заказ: 3 / 4 / 5 / 6 мм, по умолчанию 5. Предупреждений по толщине нет.
- Листы: 1000×2000 / 1250×2500 (по умолчанию) / 1500×3000 / 1500×6000 / свой.
- Ручку при раскладке не зеркалим (A не должна стать B); пластину и ухо — можно.
- В DXF: слои `SHEET` (контур листа), `CUT` (контуры и отверстия), `ENGRAVE` (только «ЛЕЗВИЕ» и стрелка на ручке). Никаких других подписей и покупного.
- Без тикета в `.claude/ticket` код не правим (CLAUDE.md).

## Review Focus

1. Количество 0 у всех деталей → «Рассчитать» не падает, показывает «нечего резать», DXF не активна.
2. Деталь больше листа (ручка 80 ≈ 800 мм на «свой» лист 500×500) → понятное сообщение «не помещается: A3-80», остальное раскладывается.
3. Большой заказ (200 пластин + 100 ручек) → расчёт не вешает вкладку навсегда: идёт с индикатором, `live()` прерывает при изменении.
4. Пустое или отрицательное поле количества / свой лист с пустой шириной → считается как 0 / прошлое значение, а не `NaN` в DXF.
5. Гравировка «ЛЕЗВИЕ» на ручке 60 профиля 1 (самая короткая прямая часть) → целиком внутри металла, у кромки лезвия, не пересекает отверстия.

### Task 3: «Рассчитать»: раскладка, DXF, цифры, «Что купить» (тикет 3)

- Modify: `drovokol-q7m4z/js/ui.js`, `index.html`, `tools/smoke.js`

**Interfaces:**
- Consumes: Task 1 (`*Part`, `bladeMark`), Task 2 (`orderParts`, `orderKey`, `normOrder`).
- Produces:
  - `nestGen(items, W, H, gap, margin, cell)` — как у коня, но флипы берутся из `item.flip` (`false` → только `[false]`), а не из `innerUp`.
  - `runOrder(o) → {sheets:[{items:[{id,name,pts,holes,engr,tr}]}], too:[name], stats:{sheets, fill, cutLen, pierces, mass, byKind}}`; масса — сталь 7850 кг/м³ × площадь без отверстий × t; врезки — по одной на контур и на каждое отверстие.
