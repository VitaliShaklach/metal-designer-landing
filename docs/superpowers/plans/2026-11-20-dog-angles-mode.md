# Режим «Углы» у собаки — план

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** на скрытой странице собаки тапами по деталям видеть на шве нарисованный угломер с транспортиром и точный угол между деталями — то число, что выставляют на приборе.

**Architecture:** чистые расчёты (пары, геометрия шва, положение угломера, цвета, логика тапов) — в новом `js/angles-core.js` без DOM и THREE, проверяются в `tools/smoke.js` на Добермане 11. Рисование угломера и карточка — в `js/angles.js` (уже есть на ветке `dog-angles`, переделывается). Числа углов — только из существующего `seamDih` (prod.js), расчёты не меняются.

**Tech Stack:** браузерный JS без сборки, three.js r128 из `vendor/` (CanvasTexture, CSS2DRenderer), Node `vm` в `smoke.js`.

**Spec:** `docs/superpowers/specs/2026-11-20-dog-angles-mode-design.md` (таблица «Решения грилинга» главнее текста выше неё).

## Global Constraints

- Работа на ветке `dog-angles` (там уже коммит «как есть, до тикета»). В `.claude/ticket` — номер тикета, иначе хук не даст править.
- Правим только `dog-k7q2m/`. `seamDih`, `partNbs`, геометрию собаки, раскрой, DXF не трогаем.
- Только локальные файлы: three.js из `../vendor/`, без CDN.
- Телефон 390 px: режим не добавляет прокрутку вбок (таблица деталей шире экрана уже сейчас — не наше).
- Любая правка JS/CSS — новая метка `?v=` во **всех** `<script>` и `<link rel="stylesheet">` `dog-k7q2m/index.html`.
- Число на модели — как в таблице: `deg = round(d > 180.5 ? 360 − d : d)`, где `d = seamDih(R, a, b)`. Вторая шкала — `180 − deg`.
- Угломер настоящего размера: головка — полукруг R = 45 мм, линейка 100 мм, толщина 1,5 мм.
- Цвета выбранных по порядку тапов, дальше по кругу: `#d0561f #8e44ad #e0b020 #c2185b #1fa2a8 #8b5a2b #f06292 #808000`. Синий `#1f6fe0` — рисунок угла, бледно-зелёный `#9fd49a` — соседи.
- Слова в карточке: «выступ» (выпуклый шов, `d ≤ 180.5`), «впадина» (вогнутый), «стык гнём, не варим», «по другой шкале N°», «№ N не стыкуется с выбранными — начал заново».
- Проверка: `npm run test:editor` (в нём `dog-k7q2m/tools/smoke.js`), потом глазами — десктоп 1440, планшет 820×1180 тапами, телефон 390.

## Review Focus

1. **Зеркальная пара (№ 12 и 12.1)** — у пары одно число, как в таблице; угломер рисуется по своей геометрии, а цифра — по `seamDih`. Тест в Task 1.
2. **Шов из нескольких рёбер** (две детали касаются ломаной) — угломер на самом длинном ребре, «шов N мм» — сумма. Тест в Task 1.
3. **Почти плоский шов (175°, 185°)** — угломер рисуется, как у всех (решение «везде одинаково»), без «линейки» и пропусков. Тест в Task 1 (gaugePose не null при 178–182°).
4. **Вогнутый шов** — головка на наружной стороне, в «ямке», подпись «впадина». Тест в Task 1 на кубе с вдавленной гранью.
5. **Смена фигуры или числа граней при включённом режиме** — выбор сбрасывается, без ошибок в консоли. Проверка глазами в Task 3.

  - `angEdges(R, a, b) → edge[]` — общие рёбра деталей a и b
  - `angAdj(R, a, b) → boolean`
  - `angPairs(R, pick:number[]) → [a, b][]` — пары с общим швом в порядке выбора (b — позже выбранная)

  - `angInfo(R, a, b, TPL, bentKey) → {d, deg, other, kind, len, tpl, bent}` — `deg` по формуле из Global Constraints, `other = 180 − deg`, `kind` `'выступ' | 'впадина'`, `len` — сумма рёбер шва, `tpl` — уголок из `TPL` (может быть null) с `a === deg` или null, `bent` — `bentKey` (Set, может быть null) содержит `bendKey(a, b)`
  - `gaugePose(R, M3, a, b, t) → {hinge, base, arm, head, deg}` — шарнир (`M` + сдвиг наружу на `t` по биссектрисе `n1 + n2`), `base` — единичный вектор прямого края головки вдоль грани a (`e1`), `arm` — вдоль грани b (`e2`), `head` — единичный вектор, куда смотрит полукруг (от прямого края, в сторону `n1`), `deg` — как в `angInfo`
  - `angTap(R, pick, pi) → {pick, note}` — повтор убирает, сосед добавляет, не сосед — `pick = [pi]` и note «№ N не стыкуется с выбранными — начал заново», `pi < 0` — без изменений
  - `ANG_COLORS` — массив из 8 цветов Global Constraints; `angColor(i) = ANG_COLORS[i % 8]`
